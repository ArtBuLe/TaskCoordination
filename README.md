# Занятие 06 — Планирование задач и управление выполнением

Три независимые диагностики запускаются совместно. Студент добавляет статусы, кооперативную отмену, тайм-аут и обработку ошибок.

## Задания
1. Проверить имя и длительность диагностики.
2. Реализовать асинхронную задержку с CancellationToken.
3. Для CPU-bound вычисления использовать Task.Run, не оборачивать им Task.Delay.
4. Запустить три диагностики одновременно.
5. Дождаться всех через Task.WhenAll.
6. Обновлять/возвращать статусы Pending, Running, Completed, Cancelled, Failed.
7. Передавать токен и регулярно проверять его в длительном цикле.
8. Реализовать CancellationTokenSource.Cancel и кооперативную отмену.
9. Добавить тайм-аут через linked CTS и CancelAfter; отличить его от внешней отмены.
10. Использовать Task.WhenAny; обработать ошибки без пустого catch.

Запуск: `dotnet run --project TaskCoordinator` и `dotnet run --project TaskCoordinator.Tests`.
